# Onepot

> Onepot (onepot.ai) is a San Francisco-based startup building an AI-powered, fully automated custom synthesis platform for small-molecule drug discovery. It searches make-on-demand molecules, scores feasibility, designs analogs, and synthesizes and QCs compounds in its US-based POT-1 lab. Onepot exposes a developer API and a first-party Python client (PyPI: onepot) for programmatic search and synthesis ordering.

This llms.txt was generated by the API Evangelist enrichment pipeline from the onepot public developer surface and the API Evangelist catalog. Source: https://www.onepot.ai/api

## APIs

- [Onepot API](https://www.onepot.ai/api): Similarity (Tanimoto) and SMILES/SMARTS substructure search over onepot CORE, retrosynthetic decomposition with building-block/price/risk filters, SSE result streaming, and synthesis ordering. API-key auth via the onepot Python client.

## Packages / SDKs

- [onepot (PyPI)](https://pypi.org/project/onepot/): First-party Python client. `pip install onepot` (or `uv add onepot`). Python 3.11+.
